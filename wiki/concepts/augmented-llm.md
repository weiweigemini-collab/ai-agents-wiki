# Augmented LLM

- 所有 agentic system 的基本積木：**LLM + 檢索（retrieval）+ 工具（tools）+ 記憶（memory）**。〔raw:01〕
- 現在的模型可以自己產生搜尋查詢、挑選工具、決定要記住什麼。〔raw:01〕
- 重點是依照用途調整這些能力，並給 LLM 一個清楚、有文件的介面。〔raw:01〕
- MCP 是實作這些擴充的一種方式，可以接上第三方工具生態系。〔raw:01〕〔raw:06〕
