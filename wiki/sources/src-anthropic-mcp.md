# Introducing the Model Context Protocol（2024-11-25）

**一句話**：用一個開放標準取代各自寫一套的整合方式，讓 AI 應用能接上資料和工具。〔raw:06〕

## 重點
- 問題：模型被困在資料孤島裡，每接一個新資料源都要客製整合。〔raw:06〕
- 架構：開發者用 MCP server 公開資料，AI 應用（MCP client）連過去。〔raw:06〕 → [[mcp]]
- 首批釋出：規格與 SDK、Claude Desktop 支援本地 server、開源 server 儲存庫。〔raw:06〕
- 預建 server：Google Drive、Slack、GitHub、Git、Postgres、Puppeteer。〔raw:06〕
